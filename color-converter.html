How the Color Converter works

All five models describe the same physical colour, so the converter keeps one source of truth — 8-bit RGB — and derives every other field from it. Edit any input and it is parsed back into RGB, after which all remaining fields repaint.

HEX ↔ RGB : each pair of hex digits is one 0–255 channel HSL : lightness = (max + min) / 2, saturation scales with distance from 0.5 HSV : value = max channel, saturation = (max − min) / max CMYK : K = 1 − max(r,g,b), then C = (1 − r − K) / (1 − K)

HSL vs HSV

Both start from the same hue angle. HSL treats 50% lightness as the pure hue and pushes to white at 100%; HSV treats 100% value as the pure hue and never reaches white unless saturation drops. Designers usually think in HSL, image editors in HSV.

About CMYK

The formula used here is the standard device-independent approximation. Real print output depends on an ICC profile and ink behaviour, so treat the CMYK numbers as a starting point.

Contrast

The panel also reports WCAG contrast ratios against black and white using relative luminance, so you can tell instantly whether text will be readable on the colour.

Color Converter FAQ

Why do CMYK values look different on screen than in print?

Screens use emitted RGB light; printing uses reflected CMYK ink. The conversion is a useful approximation, but print profiles vary.

How do I convert HEX to RGB?

Split the six-digit hex code into three pairs and convert each pair from hexadecimal to decimal. The converter does it automatically.
