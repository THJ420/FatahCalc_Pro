Define your own unit and conversion factor to convert values on a personal scale. It is useful for modelling, recipes, game rules, niche trades and any measure without a standard converter.

How to use the Custom Unit Converter

  1. Choose the source unit and the target unit from the two dropdown menus.
  2. Type a value into either box. The other box updates instantly, and editing the other box reverses the direction.
  3. Use the swap button to reverse the units, or click any row in the all-units list to make it the target.

How the Custom Unit Converter works

Every linear converter in FatahCalc Pro is the same three-line function with a different constant. This page exposes that constant so you can define units we have never heard of — price per kilo, pages per hour, coffee beans per cup.

1 unitA = factor × unitB B = A × factor (forward) A = B ÷ factor (reverse)

Optional offset

Ticking “apply an offset” switches to the affine form B = A × factor + offset, which covers scales that don't share a zero point — the same shape as the Celsius/Fahrenheit relationship (factor 1.8, offset 32).

Your definitions are saved to localStorage, so a converter you build today is still here tomorrow.

Custom Unit Converter FAQ

How do I set up a custom conversion?

Give each unit a name and a factor representing how many base units it equals, then convert between them like any other unit.

Can I save my custom units?

Custom definitions live in the current browser session and local storage, so they stay on this device.

Are my calculations private?

Yes. Every calculation runs locally in your browser. FatahCalc Pro has no analytics, no advertising and no account system, so your inputs and history stay on this device. The only network request is the live currency-rate feed, which contains no personal data.
