How to use the Currency Converter

  1. Choose the currency you are converting from and the currency you want to receive.
  2. Enter the amount. The converted value appears instantly using the latest cached reference rate.
  3. Swap the currencies for the reverse direction. Rates refresh when you are online and are marked as cached when you are offline.

How the Currency Converter works

Providers publish one table of rates against a single base currency (US dollars here), so converting between any two currencies is a cross-rate:

amount_in_USD = amount ÷ rate(from) result = amount_in_USD × rate(to)

Fetching and caching

Rates are pulled with fetch inside an async/await function, and the response is written to localStorage together with a timestamp. Subsequent visits read the cache for six hours before going back to the network — typing in the amount box never triggers a request. If every provider is unreachable (offline, blocked, rate-limited) the tool falls back to the last cached table and labels the result as stale rather than failing.

Accuracy

These are mid-market reference rates updated roughly daily. Banks and card networks add a spread of 0.5–3%, so treat the figure as an indication, not a quote.

Currency Converter FAQ

Are these exchange rates the ones my bank will use?

No. They are reference mid-market rates. Banks and card issuers add spreads and fees, so the final amount will differ.

Can I use the currency converter offline?

Yes, with the most recently cached rates. The tool marks offline rates as cached and needs a connection to refresh them.

Are my calculations private?

Yes. Every calculation runs locally in your browser. FatahCalc Pro has no analytics, no advertising and no account system, so your inputs and history stay on this device. The only network request is the live currency-rate feed, which contains no personal data.
